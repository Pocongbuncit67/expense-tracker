# Expense Tracker

A simple expense tracker built with vanilla JavaScript.

## Features
- Add, edit, and delete expenses
- Filter by category and sort by amount or date
- Total, highest expense, and totals per category
- Data saved in the browser with localStorage
- User input is escaped to prevent XSS

## What I practiced
`map`, `filter`, `reduce`, `Object.entries`, spread, destructuring, event delegation

## Run it
Open the folder in VS Code and use the Live Server extension.
